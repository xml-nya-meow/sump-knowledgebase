## 阅读方式

每次学习一个问题：先看通俗解释，再看流程图和源码位置，最后按需做练习。不要求先背完术语，也不要求一开始运行整个项目。

最新课程固定到 2026-10-29 核对的提交 `6325897cc7fa696610bc25b4c89bc77d6a7c7a43`。此前 `149451db` 十课继续保留，方便按版本学习。课程是源码分析与教学，不保证等同于以后变化的主线，也不把模拟例子当作实测。

## 事实与验证

- 源码存在不等于测试已经运行。
- 受理回执不等于工具已经完成。
- 本地夹具通过不等于所有外部产品都兼容。
- 模拟案例不是生产日志。

请勿在 issue 或提交中包含 API Key、令牌、私钥、个人目录或未脱敏日志。
